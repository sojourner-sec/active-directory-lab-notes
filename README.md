# Active Directory Lab Notes

Documenting my journey learning Active Directory; from the sysadmin side (building and managing a domain) through to the offensive side (enumeration, attacks, and eventually detection).

I'm a cybersecurity student focused on network/infrastructure penetration testing. This repo is my running notes and cheatsheet as I go; not a polished course, just an honest record of what I'm learning and building.

## What's in here

- **`sysadmin-setup/`** — Setting up my own Active Directory environment: domain controller, users, groups, OUs, and Group Policy Objects. Understanding how AD is meant to be administered before learning how it gets attacked.
- **`enumeration/`** — Notes on identifying domain structure, users, groups, and misconfigurations once I move into offensive work.
- **`attacks/`** — Writeups on specific AD attack techniques as I learn and practice them (Kerberoasting, AS-REP Roasting, lateral movement, etc.)
- **`cheatsheet.md`** — A running list of commands I've actually used, with notes on what they do. Updated continuously, not a one-time reference.

## Why this exists

I'm building this in public as part of learning network/infrastructure pentesting properly — starting with Active Directory since it's core to most real-world internal engagements. This repo will grow messily and imperfectly as I go. That's intentional.
